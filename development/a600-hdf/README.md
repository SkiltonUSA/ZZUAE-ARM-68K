# A600 HDF development launcher inputs

Source snapshot of the tested 0.6.0-dev launcher. These files overlay their
corresponding paths in the development workspace; they are not a standalone
emulator or an upgrade for the released 0.5.7 player. The IDE-enabled 0.6.0
player is required. The main release source tree remains unchanged.

[Physical results and limits](../../amiga/uae4arm/records/a600-hdf/README.md).
The accompanying launcher build manifest records all source and artifact hashes.
